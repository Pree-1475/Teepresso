# ☕ Teepresso

A custom apparel platform built with a modern, modular architecture.

## 🏗️ Architecture & Structure

This repository is structured as a monorepo containing the following core components:

- **[`teepresso-backend`](./teepresso-backend)**: Express.js API connected to Neon PostgreSQL and Google Cloud Storage.
- **[`teepresso-frontend/client-app`](./teepresso-frontend/client-app)**: The Customer Storefront (Vercel edge ready).
- **[`teepresso-frontend/admin-dashboard`](./teepresso-frontend/admin-dashboard)**: Operational Control Console (Vercel edge ready).

## 🚀 Production Endpoints

- **API Backend**: `https://teepresso-2426456693.asia-south1.run.app/api/v1`

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, PostgreSQL (Neon), Google Cloud Storage
- **Frontend:** Next.js / React (Customer Storefront & Admin Dashboard)
