# Teepresso Monorepo

Custom apparel platform with modular architecture.

## Structure
- `teepresso-backend`: Express.js API connected to Neon PostgreSQL & Google Cloud Storage
- `teepresso-frontend/client-app`: Customer Storefront (Vercel edge ready)
- `teepresso-frontend/admin-dashboard`: Operational Control Console (Vercel edge ready)
